# 루멘 마법학교

작은 학교 정원에서 맵 이동, 역할극 대화, 캐릭터 시트, 관계 기록과 탐색 퀘스트를 체험하는 첫 프로토타입입니다.

## 로컬 실행

이 폴더에서 `python3 -m http.server 4173 --directory dist`를 실행한 뒤 `http://localhost:4173`을 여세요. 별도의 패키지 설치나 빌드가 필요하지 않습니다.

## 조작

- 방향키 / WASD 또는 바닥 클릭으로 이동합니다. 모바일에서는 이동 버튼을 사용할 수 있습니다.
- 게시판·안내 캐릭터·달빛잎 가까이에서 E 또는 상호작용 버튼을 누릅니다.
- 채팅창에서 대사 / 행동 묘사를 선택합니다. Enter로 기록하고 Shift + Enter로 줄을 바꿉니다.
- 캐릭터 시트의 스탯은 주인이 직접 수정합니다. 변경 시 사유가 필요하며 성장 기록이 남습니다.
- 관계 기록은 자신의 캐릭터 시점으로 작성합니다.

## 구현 범위

현재 모든 기록은 해당 브라우저의 localStorage에 저장됩니다. 실제 다른 이용자에게 전송하지 않습니다. 맵의 미라와 리온은 정해진 안내 대사가 있는 예시 캐릭터이며 실제 접속자가 아닙니다. 이벤트는 관심 표시만 가능한 예시입니다.

회원가입, 초대 권한, 여러 기기 간 데이터 저장, 실시간 접속·채팅, 실제 이벤트 운영은 아직 연결하지 않았습니다. 친구들과 사용하는 버전에서는 계정별 소유권 검증 및 실시간 서버를 추가해야 합니다.

맵과 캐릭터는 Canvas 도형으로 직접 그립니다. 충돌 영역 및 경로 탐색으로 이동하며 물리엔진은 사용하지 않습니다. UI 폰트는 Google Fonts를 사용하고, 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 파일

- `dist/index.html`: 화면 구조
- `dist/styles.css`: 반응형 스타일
- `dist/app.js`: 맵 그리기, 이동, 데이터와 인터랙션
- `.openai/hosting.json`: Sites 배포 정보

다음 단계는 소규모 다중 접속 연결, 캐릭터 소유권 관리, 운영자용 퀘스트·이벤트 관리입니다.
